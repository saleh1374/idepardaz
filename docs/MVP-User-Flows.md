## جریان ۶: شرایط استفاده و مسئولیت

### مرحله ۱: لینک در فوتر

کاربر روی «شرایط استفاده» در فوتر کلیک می‌کند.

### مرحله ۲: صفحهٔ شرایط استفاده

```
شرایط استفاده از بساز

۱. مسئولیت ایمنی
   - پروژه‌های تأییدشده توسط تیم فنی/ایمنی بساز بازبینی شده‌اند
   - با این‌حال، مسئولیت نهایی ایمنی بر عهدهٔ کاربر است
   - همیشه هشدارهای ایمنی را رعایت کنید

۲. محدودیت سنی
   - پروژه‌های سطح HIGH برای افراد زیر ۱۸ سال بدون نظارت بزرگ‌سال مجاز نیست
   - پروژه‌های سطح CRITICAL در MVP ارائه نمی‌شوند

۳. دقت اطلاعات
   - قیمت‌ها تقریبی هستند و ممکن است تغییر کنند
   - موجودی فروشگاه‌ها به‌صورت لحظه‌ای به‌روز نمی‌شود
   - قبل از خرید، موجودی و قیمت را از فروشگاه تأیید کنید

۴. مالکیت فکری
   - Recipeها با لایسنس CC-BY-NC-4.0 منتشر شده‌اند
   - استفادهٔ تجاری با ذکر منبع مجاز است

۵. محدودیت‌های MVP
   - پروژه‌های HIGH/CRITICAL فقط برای تست داخلی
   - پرداخت آنلاین هنوز فعال نیست
   - صنعتگران فقط در حالت Waitlist هستند
```

## نکات UX مهم

### ۱. RTL فارسی
- تمام صفحات RTL هستند
- اعداد لاتین در متن فارسی قابل قبول است
- اعداد فارسی در UI نمایش داده می‌شوند

### ۲. موبایل‌فرست
- تمام صفحات Responsive هستند
- دکمه‌ها حداقل ۴۴px ارتفاع دارند
- فونت حداقل ۱۴px

### ۳. سرعت بارگذاری
- Skeleton loading برای تمام صفحات
- Lazy loading برای تصاویر
- کش سمت کلاینت

### ۴. دسترسی‌پذیری
- رنگ‌های کنتراست بالا
- توضیح alt برای تصاویر
- قابلیت ناوبری با کیبورد

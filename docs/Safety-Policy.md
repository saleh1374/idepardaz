# سیاست ایمنی و حقوقی — پلتفرم بساز

> **نسخه سند:** 1.0 — تاریخ: ۱۴۰۵/۰۷/۰۱

## ۱) سطوح ایمنی

### سطح‌بندی:

| سطح | نماد | مثال | الزامات |
|---|---|---|---|
| **LOW** | 🟢 | چراغ LED USB، فن USB، پروژه‌های Arduino 5V | هشدار متنی |
| **MEDIUM** | 🟡 | مدارهای ۱۲ ولت، موتورهای کوچک | هشدار + چک‌لیست |
| **HIGH** | 🟠 | باتری لیتیومی، پاوربانک | هشدار + تأیید اجباری + Expert Review + چک‌لیست کامل + سن ۱۸+ |
| **CRITICAL** | 🔴 | برق شهر، سیستم‌های پرقدرت | **در MVP ارائه نمی‌شود — قانون ثابت** |

### سیاست در MVP:

| سطح | اجازه | توضیح |
|---|---|---|
| LOW | ✅ Approved | ۴ Recipe فعال |
| MEDIUM | ✅ Approved | — |
| HIGH | ⚠️ آزمایشی | فقط پاوربانک (غیرعمومی) |
| CRITICAL | ❌ ممنوع | قانون ثابت پلتفرم |

## ۲) Safety Gate — دروازهٔ ایمنی اجباری

### جریان اجباری برای HIGH+:

```
صفحهٔ هشدار → تأییدیهٔ کاربر (چک‌باکس‌های جدا) → Unlock مراحل + چک‌لیست ایمنی → لاگ AuditLog
```

### پیاده‌سازی در فرانت:

```tsx
// SafetyGate.tsx
const SafetyGate = ({ level, warnings, onAccept }) => {
  const [checked, setChecked] = useState(false)
  
  return (
    <div className="rounded-2xl border-2 border-amber-300 bg-amber-50 p-6">
      <h3>⚠️ سطح ایمنی بالا — مطالعهٔ الزامی</h3>
      <p>ساخت این وسیله فقط با قطعات و نسخهٔ تأییدشدهٔ بساز مجاز است.</p>
      
      <ul>
        {warnings.map(w => <li key={w}>⚠️ {w}</li>)}
      </ul>
      
      <label>
        <input type="checkbox" checked={checked} onChange={...} />
        می‌فهمم که این کار خطرناک است و فقط با رعایت کامل دستورالعمل پیش می‌روم.
      </label>
      
      <button disabled={!checked} onClick={onAccept}>
        ورود به بخش ساخت
      </button>
    </div>
  )
}
```

## ۳) متن‌های هشدار ایمنی

### سطح LOW (پروژه‌های کم‌خطر):

```
🟢 هشدار ایمنی — سطح کم‌خطر

این پروژه با ولتاژ ایمن (۵ ولت USB) کار می‌کند؛ با این‌حال:
• هیچ‌گاه با مدار روشن لحیم‌کاری یا اتصال را لمس نکنید
• اتصال کوتاه را رعایت کنید
• در صورت گرم‌شدن LED یا مدار، فوراً جدا کنید

⚠️ این پروژه جایگزین مولتی‌متر حرفه‌ای نیست
```

### سطح MEDIUM (مدارهای ۱۲ ولت):

```
🟡 هشدار ایمنی — سطح متوسط

این پروژه با ولتاژ ۱۲ ولت کار می‌کند:
• قبل از اتصال، ولتاژ را با مولتی‌متر بررسی کنید
• اتصالات را با نوار چسب برق ایزوله کنید
• در صورت گرم‌شدن مدار، فوراً جدا کنید
• از قطعات تأییدشده استفاده کنید

⚠️ این پروژه برای افراد زیر ۱۸ سال بدون نظارت بزرگ‌سال مجاز نیست
```

### سطح HIGH (باتری لیتیومی):

```
🟠 هشدار ایمنی — سطح بالا

⚠️ این پروژه شامل باتری لیتیومی است و خطر آتش‌سوزی دارد!

الزامات ایمنی:
• فقط از سلول‌های سالم و بدون بادکردگی استفاده کنید
• حتماً از مدار حفاظت BMS استفاده کنید
• شارژ اولیه همیشه زیر نظر و دور از مواد قابل اشتعال انجام شود
• در صورت هرگونه حرارت غیرعادی، مدار را بلافاصله جدا کنید
• هرگز باتری را بدون نظارت شارژ نکنید

سن مجاز: ۱۸+ سال (بدون نظارت بزرگ‌سال مجاز نیست)
```

## ۴) شرایط استفاده (ToS)

### شرایط استفاده از بساز

**آخرین به‌روزرسانی:** ۱۴۰۵/۰۷/۰۱

### ۱. مسئولیت ایمنی

- پروژه‌های تأییدشده توسط تیم فنی/ایمنی بساز بازبینی شده‌اند
- با این‌حال، **مسئولولیت نهایی ایمنی بر عهدهٔ کاربر است**
- همیشه هشدارهای ایمنی را رعایت کنید
- در صورت بی‌احتیاطی، بساز مسئولیتی ندارد

### ۲. محدودیت سنی

- پروژه‌های سطح **HIGH** برای افراد زیر ۱۸ سال **بدون نظارت بزرگ‌سال** مجاز نیست
- پروژه‌های سطح **CRITICAL** در MVP **ارائه نمی‌شوند**

### ۳. دقت اطلاعات

- قیمت‌ها **تقریبی** هستند و ممکن است تغییر کنند
- موجودی فروشگاه‌ها به‌صورت لحظه‌ای به‌روز نمی‌شود
- **قبل از خرید، موجودی و قیمت را از فروشگاه تأیید کنید**

### ۴. مالکیت فکری

- Recipeها با لایسنس **CC-BY-NC-4.0** منتشر شده‌اند
- استفادهٔ تجاری با ذکر منبع مجاز است
- تولید محتوای مشابه با ذکر منبع مجاز است

### ۵. محدودیت‌های MVP

- پروژه‌های HIGH/CRITICAL فقط برای **تست داخلی**
- پرداخت آنلاین هنوز **فعال نیست**
- صنعتگران فقط در حالت **Waitlist** هستند
- AI فقط **StubMatcher آفلاین** است

### ۶. قوانین حاکم

- این شرایط تابع قوانین جمهوری اسلامی ایران است
- در صورت اختلاف، مرجع حل اختلاف **دادگاه تهران** است

## ۵) چک‌لیست ایمنی برای کاربر

### قبل از شروع:
- [ ] هشدارهای ایمنی پروژه را خوانده‌ام
- [ ] قطعات تأییدشده را تهیه کرده‌ام
- [ ] ابزار مناسب را دارم
- [ ] فضای کار ایمن دارم (دور از مواد قابل اشتعال)

### حین کار:
- [ ] با مدار روشن لحیم‌کاری نمی‌کنم
- [ ] اتصالات را ایزوله می‌کنم
- [ ] قطب‌ها را رعایت می‌کنم
- [ ] در صورت گرم‌شدن، فوراً جدا می‌کنم

### بعد از ساخت:
- [ ] تست نهایی را انجام می‌دهم
- [ ] اتصال کوتاه را بررسی می‌کنم
- [ ] در صورت مشکل، مدار را جدا می‌کنم

## ۶) سیاست پروژه‌های CRITICAL

### قانون ثابت پلتفرم:

> **پروژه‌های سطح CRITICAL (برق شهر، سیستم‌های پرقدرت) در MVP ارائه نمی‌شوند.**

### دلیل:
- خطر بالای برق‌گرفتگی
- نیاز به تأییدیه‌های تخصصی
- مسئولیت حقوقی سنگین

### در آینده:
- فقط با تأییدیه‌های تخصصی
- فقط برای کاربران حرفه‌ای
- با بیمهٔ مسئولیت
